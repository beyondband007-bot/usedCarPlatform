# 内饰拼图前端接口协作说明

更新时间：2026-06-01

## 1. 功能说明

内饰拼图用于把同一辆车的多张内饰图片整理为汽车电商详情页展示用拼图。

前端不需要计算拼图数量，只需要上传 2-10 张内饰图，然后把素材 ID 列表提交给后端。后端会自动分组并创建 1-3 个 Kie 图生图任务。

模块编码：

```txt
interior-collage
```

## 2. 分组规则

| 输入图片数量 | 输出拼图数量 | 分组 |
| --- | --- | --- |
| 2 | 1 | `[2]` |
| 3 | 1 | `[3]` |
| 4 | 1 | `[4]` |
| 5 | 2 | `[3, 2]` |
| 6 | 2 | `[3, 3]` |
| 7 | 2 | `[4, 3]` |
| 8 | 2 | `[4, 4]` |
| 9 | 3 | `[3, 3, 3]` |
| 10 | 3 | `[4, 3, 3]` |

规则保证：

- 总输入数量必须是 2-10 张。
- 每张输出拼图至少包含 2 张输入图片。
- 不允许重复 assetId。
- 每组会创建一个独立的 Kie 任务。

## 3. 上传内饰图片

前端先逐张上传内饰图片，复用通用上传接口。

```http
POST /api/v1/assets/upload
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | File | 是 | JPG / PNG / WebP |
| `purpose` | string | 是 | 固定传 `car_interior` |

Postman 示例：

```txt
POST http://localhost:3101/api/v1/assets/upload
Body: form-data
file: 本地内饰图
purpose: car_interior
```

响应中的 `assetId` 用于创建拼图任务。

## 4. 创建内饰拼图任务

```http
POST /api/v1/modules/interior-collage/tasks
Content-Type: application/json
```

请求体：

```json
{
  "assetIds": [
    "asset_1",
    "asset_2",
    "asset_3",
    "asset_4",
    "asset_5"
  ],
  "outputRatio": "16:9",
  "resolution": "2K"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `assetIds` | string[] | 是 | 2-10 个 `car_interior` 素材 ID |
| `outputRatio` | string | 否 | 默认 `16:9` |
| `resolution` | string | 否 | 默认 `2K` |

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "moduleCode": "interior-collage",
    "status": "queued",
    "inputImageCount": 5,
    "outputCount": 2,
    "groups": [
      {
        "groupIndex": 1,
        "inputAssetIds": ["asset_1", "asset_2", "asset_3"],
        "inputImageCount": 3
      },
      {
        "groupIndex": 2,
        "inputAssetIds": ["asset_4", "asset_5"],
        "inputImageCount": 2
      }
    ],
    "tasks": [
      {
        "taskId": "task_xxx",
        "moduleCode": "interior-collage",
        "status": "queued",
        "progress": 5,
        "kieTaskId": "kie_xxx",
        "groupIndex": 1,
        "groupCount": 2,
        "inputAssetIds": ["asset_1", "asset_2", "asset_3"],
        "inputImageCount": 3,
        "pollingUrl": "/api/v1/tasks/task_xxx"
      }
    ],
    "createdAt": "2026-06-01T10:00:00.000Z"
  },
  "requestId": "req_xxx"
}
```

说明：

- `tasks.length` 等于 `outputCount`。
- 前端需要分别轮询每个 `taskId`。
- 某个分组创建失败时，该分组任务会返回 `status=fail`，其它分组不受影响。

## 5. 轮询任务详情

```http
GET /api/v1/tasks/{taskId}
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "taskId": "task_xxx",
    "moduleCode": "interior-collage",
    "status": "success",
    "progress": 100,
    "optionId": "collage-1-of-2",
    "resultImages": [
      {
        "url": "http://localhost:3101/results/interior-collage/interior-collage_xxx.png",
        "sourceUrl": "https://..."
      }
    ]
  },
  "requestId": "req_xxx"
}
```

本地保存路径：

```txt
D:\usedCarPlatform\backend\storage\results\interior-collage\
```

## 6. 最近生成

```http
GET /api/v1/modules/interior-collage/recent-tasks?page=1&pageSize=20
```

该接口只返回内饰拼图任务，不会混入内饰清洁或其它模块。

## 7. 后端提示词

```txt
请基于本组上传的车辆内饰图片，生成一张汽车电商内饰拼图。每张拼图必须至少包含 2 张输入图片，不允许只包含 1 张图片或空白拼图。请完整展示本组图片内容，尽量避免重复和遗漏。

所有图片均为同一辆车的内饰素材。请保留每张图片中的真实内饰结构、座椅布局、方向盘、中控、仪表台、门板、地毯、天窗、后排等细节，不要改变车型、材质、颜色和空间关系，不要生成不存在的部件，不要把多张图片内容错误融合成一个空间。

拼图采用简洁规整的网格布局，图片之间间距均匀，边缘整齐，视觉平衡。统一亮度、色温、对比度和清晰度，轻微提升内饰洁净度和质感，但不要过度美化。每张小图保持原始视角和主体完整，避免裁切方向盘、座椅、中控屏、仪表盘、座椅靠背、门板等关键区域。不要添加文字、Logo、水印、边框装饰、价格标签、人物或额外物体。输出高清、真实、专业的二手车详情页内饰拼图。
```

## 8. Postman 测试顺序

1. 上传 2-10 张内饰图：

```http
POST http://localhost:3101/api/v1/assets/upload
Body: form-data
file: 本地内饰图
purpose: car_interior
```

2. 创建拼图任务：

```http
POST http://localhost:3101/api/v1/modules/interior-collage/tasks
Body: raw JSON
{
  "assetIds": ["asset_1", "asset_2", "asset_3", "asset_4", "asset_5"],
  "outputRatio": "16:9",
  "resolution": "2K"
}
```

3. 分别轮询返回的每个任务：

```http
GET http://localhost:3101/api/v1/tasks/task_xxx
```

4. 查询最近生成：

```http
GET http://localhost:3101/api/v1/modules/interior-collage/recent-tasks?page=1&pageSize=20
```
