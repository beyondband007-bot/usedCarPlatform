# 二手车AI展厅图片生成 - 技术选型方案文档

## 一、项目背景

当前项目需求：

用户上传车辆图片后：

1. 自动识别并抠出车辆主体
2. 用户选择展厅/场景模板
3. 将车辆自动融合到场景中
4. 自动生成阴影、反射、光照
5. 输出真实感展厅效果图

目标效果：

- 类似汽车之家 / 懂车帝 / AI展厅
- 接近摄影棚拍摄效果
- 支持快速批量生成

---

# 二、核心技术问题

当前项目核心技术点：

| 技术点 | 说明 |
|---|---|
| 汽车主体分割 | 从用户图片中抠出车辆 |
| 图像融合 | 将车辆融合到场景 |
| 阴影生成 | 生成车辆投影 |
| 光照统一 | 保证整体真实感 |
| 透视匹配 | 保证车辆贴合地面 |
| 场景模板化 | 支持多场景复用 |
| AI真实化 | 提升商业级真实感 |

# 四、方案一（推荐方案）

# 方案一：RMBG + OpenCV（推荐MVP方案）

## 技术栈

### 前端

```text
Vue3
TypeScript
Element Plus
Pinia
```

### 后端

```text
Python
FastAPI
```

### AI部分

```text
RMBG-2.0
OpenCV
Pillow
NumPy
```

## 技术流程

```text
用户上传图片
    ↓
RMBG自动抠图
    ↓
输出透明PNG
    ↓
OpenCV进行场景合成
    ↓
自动生成阴影
    ↓
输出结果图
```

## 优点

| 优点 | 说明 |
|---|---|
| 开发快 | 适合快速上线 |
| 成本低 | 无需高GPU |
| 稳定性高 | 可控性强 |
| 速度快 | 生成速度快 |
| 易维护 | 逻辑简单 |
| 商业可落地 | 企业常用方案 |

## 缺点

| 缺点 | 说明 |
|---|---|
| AI感较弱 | 本质仍偏传统CV |
| 光影有限 | 阴影真实性一般 |
| 复杂场景有限 | 夜景等效果较弱 |
| 极致真实感不足 | 与真实摄影仍有差距 |

## 推荐指数

★★★★★

## 适用阶段

- MVP阶段

# 十一、场景模板标准化（非常重要）

建议每个场景配置：

```json
{
  "sceneId": 1,
  "name": "经典白棚",
  "carX": 320,
  "carY": 420,
  "scale": 0.82,
  "shadowOpacity": 0.35,
  "shadowBlur": 25,
  "lightDirection": "left"
}
```

## 作用

| 功能 | 说明 |
|---|---|
| 自动摆放 | 车辆自动定位 |
| 自动缩放 | 不同车型适配 |
| 自动阴影 | 根据场景生成 |
| 自动光照 | 场景统一 |
