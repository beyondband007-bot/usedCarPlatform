# 营销工具前端接口协作说明

更新时间：2026-05-30

## 1. 范围

本文档覆盖视觉工作台左侧“营销工具”分组：

- 去水印：`watermark-remove`
- 创意生图：`creative-image`
- 短视频生成：`short-video`

第一版不做登录、不做积分扣减，用户固定为 `default_user`。前端不需要展示“文生图/图生图”概念，创意生图统一调用一个生成接口，后端按是否有参考图自动选择模型。

## 2. 通用约定

Base URL：

```txt
/api/v1
```

统一响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "requestId": "req_xxx"
}
```

任务详情轮询：

```http
GET /api/v1/tasks/{taskId}
```

模块最近生成：

```http
GET /api/v1/modules/{moduleCode}/recent-tasks?page=1&pageSize=20
```

## 3. 素材上传

通用上传接口：

```http
POST /api/v1/assets/upload
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | File | 是 | JPG / PNG / WebP |
| `purpose` | string | 是 | 车辆外观图使用 `car_exterior` |

## 4. 去水印

创建任务：

```http
POST /api/v1/modules/watermark-remove/tasks
Content-Type: application/json
```

请求：

```json
{
  "inputAssetId": "asset_xxx",
  "outputRatio": "16:9",
  "resolution": "2K"
}
```

最近生成：

```http
GET /api/v1/modules/watermark-remove/recent-tasks?page=1&pageSize=20
```

## 5. 短视频生成

创建任务：

```http
POST /api/v1/modules/short-video/tasks
Content-Type: application/json
```

请求：

```json
{
  "inputAssetId": "asset_xxx",
  "outputRatio": "16:9",
  "extra": {
    "videoResolution": "720p"
  }
}
```

说明：

- 使用 Kie Seedance 2.0：`bytedance/seedance-2`
- 上传图作为 `reference_image_urls`
- 视频固定 10 秒
- 默认 `16:9`、`720p`

最近生成：

```http
GET /api/v1/modules/short-video/recent-tasks?page=1&pageSize=20
```

## 6. 创意生图

模块编码：

```txt
creative-image
```

用途：支持“直接输入提示词生成图片”“上传/选择参考图后生成图片”“基于某张不满意的结果图继续修改”。后端不接语言模型，不做提示词润色，用户输入的 `prompt` 原样进入 Kie。

后端自动选择：

| 前端行为 | 后端 generationMode | Kie 模型 |
| --- | --- | --- |
| 未传参考图 | `text_to_image` | `gpt-image-2-text-to-image` |
| 传 `referenceAssetId` | `image_to_image` | `gpt-image-2-image-to-image` |
| 传 `useLastReference=true` | `image_to_image` | `gpt-image-2-image-to-image` |
| 传 `sourceTaskId + sourceImageUrl` | `revise` | `gpt-image-2-image-to-image` |

### 6.1 新建对话

```http
POST /api/v1/modules/creative-image/conversations
Content-Type: application/json
```

请求：

```json
{
  "title": "夜晚车库广告图"
}
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "conversationId": "creative_conv_xxx",
    "title": "夜晚车库广告图",
    "status": "active",
    "lastMessage": null,
    "lastTaskId": null,
    "lastResultUrl": null,
    "createdAt": "2026-05-30T10:00:00.000Z",
    "updatedAt": "2026-05-30T10:00:00.000Z"
  },
  "requestId": "req_xxx"
}
```

### 6.2 历史记录

对话列表：

```http
GET /api/v1/modules/creative-image/conversations?page=1&pageSize=20
```

对话详情：

```http
GET /api/v1/modules/creative-image/conversations/{conversationId}
```

对话消息：

```http
GET /api/v1/modules/creative-image/conversations/{conversationId}/messages
```

消息会返回 `prompt/taskId/referenceAssetId/sourceTaskId/sourceImageUrl/generationMode`，前端用 `taskId` 轮询任务详情后渲染图片卡片。

### 6.3 上传并绑定参考图

```http
POST /api/v1/modules/creative-image/conversations/{conversationId}/assets
Content-Type: multipart/form-data
```

表单字段：

```txt
file: 本地车辆图片
purpose: car_exterior
```

响应中的 `assetId` 可作为后续生成接口的 `referenceAssetId`。

### 6.4 统一创建生成任务

```http
POST /api/v1/modules/creative-image/conversations/{conversationId}/generations
Content-Type: application/json
```

不传参考图，自动文生图：

```json
{
  "prompt": "一辆白色 SUV 停在夜晚高级车库中，电影感灯光，真实汽车广告摄影",
  "outputRatio": "16:9",
  "resolution": "2K"
}
```

传参考图，自动图生图：

```json
{
  "prompt": "保持车辆主体一致，背景改成高级黑色展厅，提升车漆反光",
  "referenceAssetId": "asset_xxx",
  "outputRatio": "16:9",
  "resolution": "2K"
}
```

使用当前对话最近上传的参考图：

```json
{
  "prompt": "基于刚才上传的车图生成一张高级广告图",
  "useLastReference": true,
  "outputRatio": "16:9",
  "resolution": "2K"
}
```

点击“修改这张图”：

```json
{
  "prompt": "继续优化这张图，保持主体一致，提升真实感和地面反射",
  "sourceTaskId": "task_xxx",
  "sourceImageUrl": "http://localhost:3101/results/creative-image/creative-image_xxx.png",
  "outputRatio": "16:9",
  "resolution": "2K"
}
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "conversationId": "creative_conv_xxx",
    "taskId": "task_xxx",
    "moduleCode": "creative-image",
    "status": "queued",
    "progress": 5,
    "kieTaskId": "kie_xxx",
    "generationMode": "image_to_image",
    "referenceAssetId": "asset_xxx",
    "sourceTaskId": null,
    "sourceImageUrl": null,
    "outputRatio": "16:9",
    "resolution": "2K",
    "pollingUrl": "/api/v1/tasks/task_xxx",
    "createdAt": "2026-05-30T10:00:00.000Z"
  },
  "requestId": "req_xxx"
}
```
