# 批量上新与成片交付前端接口协作说明

更新时间：2026-05-29

## 1. 统一约定

- Base URL：`http://localhost:3101/api/v1`
- 响应包裹：`{ code, message, data, requestId }`
- 第一版不做登录、不做积分扣减，所有账号相关数据默认归属 `default_user`。
- 第一版不限制上传套数；后续接用户等级后，低等级最多 1 套，高等级可多套并发。
- 成片交付是统一交付中心：运行中、已完成、后续下载包状态都从成片交付模块读取。

任务状态：

```txt
waiting | queued | generating | success | fail | canceled
```

素材上传仍复用：

```http
POST /api/v1/assets/upload
Body: multipart/form-data
```

| purpose | 用途 |
| --- | --- |
| `car_exterior` | 批量外观图 |
| `car_interior` | 批量内饰图 |
| `logo` | 默认 Logo / 车牌标识 |

## 2. 内饰清洁模块

接口：

```http
POST /api/v1/modules/interior-clean/tasks
Content-Type: application/json
```

请求体：

```json
{
  "inputAssetId": "内饰图assetId"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `inputAssetId` | string | 是 | 上传车辆内饰图返回的 `assetId`，素材 `purpose` 必须是 `car_interior` |

后端固定使用 prompt：

```txt
对上传车辆内饰图，对车内空间进行清洁增强处理，重点提升方向盘、座椅、仪表台、中控区域、门板及地毯区域的整洁度与清爽感。保留原车内饰结构、布局、材质、颜色和拍摄角度不变，清除灰尘、污渍、使用痕迹和杂乱感，使内饰表面看起来更加干净、细致、清爽自然；同时增强皮革、塑料、金属与织物等材质的质感表现，让整车内饰呈现焕然一新、整洁舒适的视觉效果。
```

轮询仍使用：

```http
GET /api/v1/tasks/{taskId}
```

## 3. 批量视觉预设

查询预设：

```http
GET /api/v1/modules/batch-new/presets
```

保存或更新预设：

```http
POST /api/v1/modules/batch-new/presets
Content-Type: application/json
```

```json
{
  "presetId": "tpl-may-showroom",
  "name": "5月展厅批量上新",
  "visualConfig": {
    "enableSceneChange": true,
    "sceneOptionId": "white-studio",
    "sceneIndex": 0,
    "sceneCategory": "展厅灯光",
    "outputRatio": "1:1",
    "useRecentLogo": false,
    "enableLightConsistency": true,
    "enablePaintRefresh": false,
    "enableInteriorClean": false
  }
}
```

前端字段映射：

| 当前前端字段 | 后端字段 |
| --- | --- |
| `enableSceneChange` | `visualConfig.enableSceneChange` |
| `batchSceneIndex` | `visualConfig.sceneIndex` |
| `batchSceneCategory` | `visualConfig.sceneCategory` |
| `outputRatio` | `visualConfig.outputRatio` |
| `useRecentLogo` | `visualConfig.useRecentLogo` |
| `lightConsistency` | `visualConfig.enableLightConsistency` |
| `paintRefresh` | `visualConfig.enablePaintRefresh` |
| `interiorEnhance` | `visualConfig.enableInteriorClean` |

## 4. 创建批量上新任务

```http
POST /api/v1/modules/batch-new/tasks
Content-Type: application/json
```

```json
{
  "projectName": "5月展厅批量上新",
  "presetId": "tpl-may-showroom",
  "carGroups": [
    {
      "groupTitle": "捷途 X70",
      "exteriorAssetIds": ["asset_ext_1", "asset_ext_2"],
      "interiorAssetIds": ["asset_int_1"]
    }
  ],
  "visualConfig": {
    "enableSceneChange": true,
    "sceneOptionId": "white-studio",
    "sceneIndex": 0,
    "sceneCategory": "展厅灯光",
    "outputRatio": "1:1",
    "useRecentLogo": false,
    "enableLightConsistency": true,
    "enablePaintRefresh": false,
    "enableInteriorClean": true
  }
}
```

说明：

- `carGroups[]` 的每一项是一套车图。
- `exteriorAssetIds` 必填，可以一套多张外观图。
- `interiorAssetIds` 选填，只有开启 `enableInteriorClean` 时才会创建内饰增强子任务。
- 如果开启 `useRecentLogo`，后端使用当前账号默认 Logo；第一版账号为 `default_user`。
- 如果开启 `enableSceneChange`，后端追加预设场景参考图。

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "batchId": "batch_xxx",
    "projectName": "5月展厅批量上新",
    "status": "queued",
    "total": 3,
    "completed": 0,
    "failed": 0,
    "progress": 5,
    "pollingUrl": "/api/v1/modules/batch-new/tasks/batch_xxx",
    "estimatedCost": 360,
    "balance": 0,
    "createdAt": "2026-05-29T10:00:00.000Z"
  },
  "requestId": "req_xxx"
}
```

## 5. 查询批量任务详情

```http
GET /api/v1/modules/batch-new/tasks/{batchId}
```

说明：

- 该接口会刷新 Kie 子任务状态。
- 该接口会按 Kie Key 并发余量提交等待中的子任务。
- 前端可每 5-10 秒轮询一次。

响应核心字段：

```json
{

  "projectName": "5月展厅批量上新",

      "inputAssetId": "asset_ext_1",
      "generationTaskId": "task_xxx",
      "status": "success",
      "progress": 100,
      "resultCount": 1,
      "error": null

  ]
}
```

## 6. 成片交付统一看板

```http
GET /api/v1/modules/delivery/tasks
```

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `status` | 否 | 可过滤 `waiting/queued/generating/success/fail` |
| `page` | 否 | 默认 1 |
| `pageSize` | 否 | 默认 20 |

说明：

- 正在运行中的批量任务也会返回。
- 已产出的子任务图片会进入 `assetCount`。
- 下载包状态通过 `downloadPackageStatus` 和 `latestPackageId` 展示。

```json
{
  "items": [
    {
      "taskId": "batch_xxx",
      "taskType": "batch",
      "title": "5月展厅批量上新 · 成片交付",
      "status": "generating",
      "progress": 42,
      "total": 3,
      "completed": 1,
      "failed": 0,
      "assetCount": 1,
      "downloadableAssetCount": 1,
      "downloadPackageStatus": null,
      "latestPackageId": null,
      "createdAt": "2026-05-29T10:00:00.000Z",
      "updatedAt": "2026-05-29T10:03:00.000Z"
    }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 1
}
```

## 7. 成片素材与下载包

查询某个批量任务已产出素材：

```http
GET /api/v1/modules/delivery/tasks/{batchId}/assets
```

创建下载包：

```http
POST /api/v1/modules/delivery/packages
Content-Type: application/json
```

```json
{
  "taskId": "batch_xxx",
  "packageName": "5月展厅批量上新",
  "assetIds": ["delivery_task_xxx_0"]
}
```

查询下载包：

```http
GET /api/v1/modules/delivery/packages/{packageId}
GET /api/v1/modules/delivery/packages?taskId={batchId}
```

删除成片素材：

```http
DELETE /api/v1/modules/delivery/assets
Content-Type: application/json
```

```json
{
  "assetIds": ["delivery_task_xxx_0"]
}
```

## 8. Postman 验收顺序

1. 上传外观图：`POST /api/v1/assets/upload`，`purpose=car_exterior`。
2. 可选上传内饰图：`POST /api/v1/assets/upload`，`purpose=car_interior`。
3. 保存视觉预设：`POST /api/v1/modules/batch-new/presets`。
4. 创建批量任务：`POST /api/v1/modules/batch-new/tasks`。
5. 轮询批量详情：`GET /api/v1/modules/batch-new/tasks/{batchId}`。
6. 查看成片交付看板：`GET /api/v1/modules/delivery/tasks`。
7. 查看已产出素材：`GET /api/v1/modules/delivery/tasks/{batchId}/assets`。
8. 创建下载包：`POST /api/v1/modules/delivery/packages`。
9. 查询下载包：`GET /api/v1/modules/delivery/packages/{packageId}`。
