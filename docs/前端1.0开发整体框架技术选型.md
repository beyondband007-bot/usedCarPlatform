# 二、前端技术选型

## 2.1 核心技术栈

| 技术       | 说明         |
| ---------- | ------------ |
| Vue3       | 前端核心框架 |
| TypeScript | 类型系统     |

# 三、项目整体架构

## 3.1 项目结构

```txt
src
├─ api                接口层
├─ assets             静态资源
├─ business           业务模块
│
├─ components         公共组件
├─ composables        hooks
├─ constants          常量
├─ directives         指令
├─ layouts            布局
├─ pages              页面
├─ router             路由
├─ services           服务层
├─ stores             状态管理
├─ styles             全局样式
├─ types              TS类型
├─ utils              工具方法
└─ workers            Web Worker
