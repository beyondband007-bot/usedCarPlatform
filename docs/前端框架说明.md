## 1. 项目概览

当前前端是一个基于 Vue 3 的汽车内容生成工作台，页面由全局布局、主页、企业登录、积分/套餐页、视觉工作台、历史记录等模块组成。

核心特点：

- 支持日间 / 夜间双主题
- 以 CSS 变量管理全局颜色体系
- 以工作台能力模块拆分页面逻辑
- 使用 Naive UI + Tailwind CSS 组合实现基础交互与局部样式

## 2. 目录结构

以下为当前前端的主要目录结构，重点列出和页面、主题、业务组件相关的部分。

```text
src/
├─ api/                  # 接口封装
├─ assets/               # 静态资源
├─ business/             # 业务模块相关内容
├─ components/           # 公共组件与业务组件
│  ├─ common/            # 通用组件
│  ├─ layout/            # 布局组件
│  └─ business/          # 业务组件
├─ composables/          # 组合式逻辑
├─ constants/            # 常量与配置
├─ directives/           # 自定义指令
├─ img/                  # 页面图片资源
├─ layouts/              # 页面布局
├─ mock/                 # Mock 数据
├─ pages/                # 页面级路由视图
├─ router/               # 路由
├─ services/             # 服务层封装
├─ stores/               # Pinia 状态
├─ styles/               # 全局样式与主题变量
├─ types/                # TypeScript 类型
├─ utils/                # 工具函数
└─ workers/              # Web Worker 相关逻辑
```

更关键的业务页面路径如下：

## 7. 结论

当前前端结构的核心是“全局主题变量 + 页面级模块拆分 + 工作台业务组件化”。  
日间 / 夜间主题通过 `src/styles/index.scss` 统一控制，工作台页面再通过各自的局部变量覆盖具体背景和边框，从而实现同一产品内的视觉一致性。
