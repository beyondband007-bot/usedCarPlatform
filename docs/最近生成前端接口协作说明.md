# 最近生成前端接口协作说明

更新时间：2026-05-29

## 1. 本次修复

之前 `GET /api/v1/tasks` 在不传模块编码时会返回所有模块的任务，导致“展厅灯光”的生成记录会出现在“户外场景、道路动态、天空影棚”等其它模块的最近生成页签中。

修复后：

- 模块内“最近生成”必须按模块查询。
- 推荐前端使用模块分层接口：`GET /api/v1/modules/{moduleCode}/recent-tasks`。
- 兼容接口 `GET /api/v1/tasks` 仍保留，但模块页必须传 `moduleCode`。
- 如果确实需要全局最近生成列表，必须显式传 `scope=all`。

## 2. 推荐接口：模块最近生成

```http
GET /api/v1/modules/{moduleCode}/recent-tasks
```

用途：某个视觉模块内部的“最近生成”页签，只返回当前模块的等待中、生成中、成功、失败历史。

模块编码：

| 模块 | moduleCode |
| --- | --- |
| 展厅灯光 | `showroom-light` |
| 户外场景 | `outdoor-scene` |
| 道路动态 | `road-motion` |
| 天空影棚 | `sky-studio` |
| 烤漆翻新 | `paint-refresh` |
| 光污一致化 | `light-consistency` |
| 内饰清洁 | `interior-clean` |
| 去水印 | `watermark-remove` |
| 批量上新子任务 | `batch-new` |

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `status` | string | 否 | `waiting/queued/generating/success/fail/canceled` |
| `page` | number | 否 | 默认 1 |
| `pageSize` | number | 否 | 默认 20，最大 100 |

Postman 示例：

```http
GET http://localhost:3101/api/v1/modules/showroom-light/recent-tasks?page=1&pageSize=20
```

只看生成中：

```http
GET http://localhost:3101/api/v1/modules/showroom-light/recent-tasks?status=generating&page=1&pageSize=20
```

## 3. 兼容接口：按模块查询

```http
GET /api/v1/tasks?moduleCode={moduleCode}
```

模块页面也可以继续使用这个接口，但必须传 `moduleCode`。

Postman 示例：

```http
GET http://localhost:3101/api/v1/tasks?moduleCode=showroom-light&page=1&pageSize=20
```

如果不传 `moduleCode`，后端会返回参数错误，避免前端误展示其它模块的记录：

```json
{
  "code": 40003,
  "message": "moduleCode is required for module recent list. Use scope=all only for global recent list.",
  "data": null,
  "requestId": "req_xxx"
}
```

## 4. 全局最近生成

仅当后续有“全部最近生成”页面时使用：

```http
GET /api/v1/tasks?scope=all&page=1&pageSize=20
```

注意：模块内部页签不要使用 `scope=all`。

## 6. 前端对接要求

- 展厅灯光最近生成：调用 `GET /api/v1/modules/showroom-light/recent-tasks`。
- 户外场景最近生成：调用 `GET /api/v1/modules/outdoor-scene/recent-tasks`。
- 道路动态最近生成：调用 `GET /api/v1/modules/road-motion/recent-tasks`。
- 天空影棚最近生成：调用 `GET /api/v1/modules/sky-studio/recent-tasks`。
- 烤漆翻新最近生成：调用 `GET /api/v1/modules/paint-refresh/recent-tasks`。
- 光污一致化最近生成：调用 `GET /api/v1/modules/light-consistency/recent-tasks`。
- 内饰清洁最近生成：调用 `GET /api/v1/modules/interior-clean/recent-tasks`。
- 批量上新子任务最近生成：调用 `GET /api/v1/modules/batch-new/recent-tasks`。

字段映射：

| 前端字段 | 后端字段 | 说明 |
| --- | --- | --- |
| `WorkspaceRecentItem.id` | `id` | 本地任务 ID |
| `title` | `title` | 后端按模块生成默认标题 |
| `status` | `uiStatus` 或 `status` | 旧前端如使用 `queue`，取 `uiStatus`；新前端建议使用 `status=queued` |
| `createdAt` | `createdAt` | ISO 时间 |
| `thumbnail` | `thumbnail` | 成功时为结果图；未成功时为上传原图 |
| `previewImage` | `previewImage` | 大图预览 |
| `ratioLabel` | `ratioLabel` | 例如 `主图 16:9` |
| `sceneLabel` | `sceneLabel` | 场景/选项 ID，前端可映射成中文标题 |

## 7. 状态说明

后端标准状态：

```txt
waiting | queued | generating | success | fail | canceled
```

为兼容旧前端，接口额外返回：

```json
{
  "status": "queued",
  "uiStatus": "queue"
}
```

后续建议前端统一改为 `queued`。

## 8. 详情轮询

点击单个最近生成卡片或刷新未完成任务时，继续使用：

```http
GET /api/v1/tasks/{taskId}
```

该接口按任务 ID 查询详情，不参与模块列表筛选。
