# 最近生成前端接口协作说明

更新时间：2026-05-29

## 1. 用途

“最近生成”页签统一展示所有后端生成任务，包括：

- 等待中：`waiting`
- 已提交排队：`queued`
- 生成中：`generating`
- 已成功：`success`
- 已失败：`fail`
- 已取消：`canceled`

该接口覆盖单图模块和批量上新的子任务历史。批量任务整体看板仍使用成片交付模块。

## 2. 查询最近生成列表

```http
GET /api/v1/tasks
```

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `moduleCode` | string | 否 | 按模块过滤，例如 `showroom-light`、`paint-refresh`、`batch-new` |
| `status` | string | 否 | 按任务状态过滤：`waiting/queued/generating/success/fail/canceled` |
| `page` | number | 否 | 默认 1 |
| `pageSize` | number | 否 | 默认 20，最大 100 |

Postman 示例：

```http
GET http://localhost:3101/api/v1/tasks?page=1&pageSize=20
```

按模块查询：

```http
GET http://localhost:3101/api/v1/tasks?moduleCode=paint-refresh&page=1&pageSize=20
```

查询生成中：

```http
GET http://localhost:3101/api/v1/tasks?status=generating&page=1&pageSize=20
```

## 4. 前端字段映射

| 前端字段 | 后端字段 | 说明 |
| --- | --- | --- |
| `WorkspaceRecentItem.id` | `id` | 本地任务 ID |
| `title` | `title` | 后端按模块生成默认标题 |
| `status` | `uiStatus` 或 `status` | 旧前端如使用 `queue`，取 `uiStatus`；新前端建议取 `status=queued` |
| `createdAt` | `createdAt` | ISO 时间 |
| `thumbnail` | `thumbnail` | 成功时为结果图；未成功时为上传原图 |
| `previewImage` | `previewImage` | 同上，可用于大图预览 |
| `ratioLabel` | `ratioLabel` | 例如 `主图 16:9` |
| `sceneLabel` | `sceneLabel` | 场景/选项 ID，可再映射成中文标题 |

## 5. 前端使用建议

- 最近生成页首次进入时调用：

```http
GET /api/v1/tasks?page=1&pageSize=20
```

- 如果前端在某个模块内部展示最近生成，传 `moduleCode`。
- 对 `waiting/queued/generating` 项，前端可每 3-5 秒刷新列表，或者点击单项后继续调用：

```http
GET /api/v1/tasks/{taskId}
```

- `thumbnail` 为空时前端展示占位图；正常情况下后端会返回上传原图作为等待/生成中的缩略图。

## 6. 状态兼容说明

后端标准状态是：

```txt
waiting | queued | generating | success | fail | canceled
```

当前前端旧类型里可能写了 `queue`，因此接口额外返回：

```json
{
  "status": "queued",
  "uiStatus": "queue"
}
```

后续建议前端统一改为 `queued`。
