# 视觉工作台后端接口文档 V1

## 1. 文档目标

本文档用于定义“视觉工作台”第一版前后端接口契约，覆盖当前前端页面中已经出现的功能面：

- 素材上传
- 工作台能力配置
- 单图生成
- 最近生成
- 批量上新
- 批量视觉处理配置
- 成片交付

第一版不做登录、不做积分扣减。接口中保留 `estimatedCost`、`balance` 等字段，仅用于前端展示和后续兼容，不参与鉴权、扣费或权限判断。

任务进度采用 REST 轮询：创建任务后返回 `taskId` 或 `batchId`，前端定时调用详情接口获取状态、进度和结果。Socket.IO 事件可以作为后续增强，不作为第一版必需链路。

## 2. 统一约定

### 2.1 Base URL

```txt
/api/v1
```

### 2.2 响应结构

所有接口统一返回：

```ts
interface ApiResponse<T> {
  code: number
  message: string
  data: T
  requestId: string
}
```

成功示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "requestId": "req_20260528120000001"
}
```

失败示例：

```json
{
  "code": 40001,
  "message": "file type is not supported",
  "data": {
    "field": "file",
    "reason": "only jpg, png, webp are allowed"
  },
  "requestId": "req_20260528120000002"
}
```

### 2.3 时间格式

所有时间字段使用 ISO 8601 字符串：

```txt
2026-05-28T12:00:00+08:00
```

### 2.4 任务状态

```ts
type WorkspaceTaskStatus =
  | 'waiting'
  | 'queued'
  | 'generating'
  | 'success'
  | 'fail'
  | 'canceled'
```

状态说明：

| 状态 | 含义 |
| --- | --- |
| `waiting` | 已创建，等待进入队列 |
| `queued` | 已进入队列，等待执行 |
| `generating` | 生成中 |
| `success` | 已完成 |
| `fail` | 失败 |
| `canceled` | 已取消 |

### 2.5 分页结构

```ts
interface PageResult<T> {
  items: T[]
  page: number
  pageSize: number
  total: number
}
```

## 4. 接口详情

### 4.1 上传素材

```txt
POST /api/v1/assets/upload
Content-Type: multipart/form-data
```

用途：上传车辆外观图、内饰图、Logo、批量素材包或交付素材。

请求参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | File | 是 | 上传文件 |
| `purpose` | string | 是 | `car_exterior`、`car_interior`、`logo`、`batch_package`、`delivery_asset` |

文件限制：

| purpose | 支持格式 | 建议限制 |
| --- | --- | --- |
| `car_exterior` | JPG、PNG、WebP | 单文件不超过 20MB |
| `car_interior` | JPG、PNG、WebP | 单文件不超过 20MB |
| `logo` | PNG、SVG | 单文件不超过 5MB |
| `batch_package` | ZIP、CSV、JPG、PNG、WebP | 单文件不超过 200MB |
| `delivery_asset` | JPG、PNG、WebP、ZIP | 单文件不超过 200MB |

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "assetId": "asset_10001",
    "purpose": "car_exterior",
    "url": "https://cdn.example.com/assets/asset_10001.jpg",
    "thumbnailUrl": "https://cdn.example.com/assets/asset_10001_thumb.jpg",
    "fileName": "bmw-front.jpg",
    "mimeType": "image/jpeg",
    "size": 2388120,
    "width": 1920,
    "height": 1280,
    "createdAt": "2026-05-28T12:00:00+08:00"
  },
  "requestId": "req_10001"
}
```

前端使用场景：

- 单图能力中的车辆图片上传。
- 场景生成中的 Logo 上传。
- 批量上新中的外观图组、内饰图组或 ZIP 包上传。

### 4.3 创建单图生成任务

```txt
POST /api/v1/workspace/tasks
Content-Type: application/json
```

用途：创建单张图片生成任务，包括场景影棚、车辆美容和内饰增强能力。

请求参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `apiCode` | string | 是 | 能力编码，如 `scene_showroom_light` |
| `inputAssetId` | string | 是 | 上传后的车辆图片素材 ID |
| `optionId` | string | 否 | 模板或处理方向 ID |
| `outputRatio` | string | 是 | `1:1`、`3:4`、`4:3`、`9:16`、`16:9` |
| `useLogo` | boolean | 是 | 是否使用 Logo |
| `logoAssetId` | string | 否 | Logo 素材 ID，`useLogo=true` 且不用最近 Logo 时传 |
| `title` | string | 否 | 任务标题，不传由后端按能力和模板生成 |

请求示例：

```json
{
  "apiCode": "scene_showroom_light",
  "inputAssetId": "asset_10001",
  "optionId": "white-studio",
  "outputRatio": "1:1",
  "useLogo": true,
  "logoAssetId": "asset_logo_10001",
  "title": "宝马 5 系经典白棚"
}
```

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "taskId": "task_10001",
    "status": "waiting",
    "progress": 0,
    "pollingUrl": "/api/v1/workspace/tasks/task_10001",
    "estimatedCost": 15,
    "balance": 1250,
    "createdAt": "2026-05-28T12:00:00+08:00"
  },
  "requestId": "req_10003"
}
```

前端使用场景：

- 点击单图“生成”按钮后创建任务。
- 创建成功后开始定时调用任务详情接口。

```txt
POST /api/v1/workspace/tasks/{taskId}/cancel
```

用途：取消尚未完成的单图生成任务。

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "taskId": "task_10001",
    "status": "canceled",
    "updatedAt": "2026-05-28T12:01:00+08:00"
```

## 5. 错误码

| HTTP 状态 | code | message | 场景 |
| --- | --- | --- | --- |
| 400 | 40001 | `file type is not supported` | 文件类型不支持 |
| 400 | 40002 | `file is too large` | 文件超限 |
| 400 | 40003 | `invalid parameter` | 参数错误 |
| 404 | 40401 | `asset not found` | 素材不存在 |
| 404 | 40402 | `task not found` | 任务不存在 |
| 409 | 40901 | `task cannot be canceled` | 任务状态不允许取消 |
| 500 | 50001 | `generation failed` | 生成失败 |
| 500 | 50002 | `package failed` | 下载包打包失败 |

第一版不定义 401/403 业务语义；登录、企业账号、权限和积分扣减后续版本再补。

## 6. 前端接入映射

### 6.1 静态能力配置替换

当前前端常量 `workspaceCapabilities` 可由 `GET /workspace/capabilities` 替换。

关键映射：

| 前端字段 | 后端字段 | 说明 |
| --- | --- | --- |
| `code` | `code` | 前端路由/选中状态使用 |
| `apiCode` | `apiCode` | 后端生成能力编码 |
| `kind` | `kind` | 控制页面分支：单图、批量、交付 |
| `options` | `options` | 模板选择 |
| `recent` | `recent` 或 `GET /workspace/tasks` | 最近生成 |
| `cost` | `estimatedCost` | 第一版仅展示 |
| `balance` | `balance` | 第一版仅展示 |

### 6.2 单图生成流程

```txt
上传车辆图 -> POST /assets/upload
选择能力和模板 -> POST /workspace/tasks
轮询任务详情 -> GET /workspace/tasks/{taskId}
展示结果图 -> data.results
刷新最近生成 -> GET /workspace/tasks
```

### 6.3 批量上新流程

```txt
上传外观/内饰图组 -> POST /assets/upload
读取或保存视觉预设 -> GET/POST /workspace/batch/presets
创建批量任务 -> POST /workspace/batch/tasks
轮询批量详情 -> GET /workspace/batch/tasks/{batchId}
进入成片交付 -> GET /workspace/delivery/tasks
```

### 6.4 成片交付流程

```txt
查询可交付任务 -> GET /workspace/delivery/tasks
选中任务 -> GET /workspace/delivery/tasks/{taskId}/assets
选择素材 -> POST /workspace/delivery/packages
轮询下载包 -> GET /workspace/delivery/packages/{packageId}
下载 ZIP -> downloadUrl
```

## 7. Mock 验证场景

### 7.1 单图生成成功

- 上传一张外观图，返回 `assetId`。
- 创建 `scene_showroom_light` 任务，返回 `taskId`。
- 轮询任务详情，状态从 `waiting` 到 `queued` 到 `generating` 到 `success`。
- `success` 时返回至少一张 `results` 图片。
- 右侧最近生成出现该任务。

### 7.2 单图生成失败

- 创建任务后轮询详情。
- 详情返回 `status=fail`、`error.code` 和 `error.message`。
- 前端停止轮询并展示失败原因。

### 7.3 批量任务成功

- 上传多个外观图素材。
- 创建批量任务。
- 轮询批量详情，`completed + failed` 最终等于 `total`。
- 完成后在成片交付列表中能查询到该任务。

### 7.4 下载包生成

- 查询交付任务结果图。
- 选择多个 `assetId` 创建下载包。
- 轮询下载包详情。
- 成功后返回 `downloadUrl`。

### 7.5 参数和文件异常

- 上传不支持格式返回 `40001`。
- 上传超限文件返回 `40002`。
- 查询不存在任务返回 `40402`。
- 下载包生成失败返回 `status=fail` 和错误信息。

## 8. 后续增强预留

- 登录和企业账号：后续可在请求头接入 `Authorization`，并补充 401/403 语义。
- 积分系统：后续将 `estimatedCost`、`balance` 接入真实扣减和流水。
- Socket.IO：后续可复用当前前端 `socket.ts` 中的 `task:*`、`image:*`、`batch:*` 事件替代或补充 REST 轮询。
- AI 引擎：接口不绑定具体实现，后端可以接 FastAPI/RMBG/OpenCV、ComfyUI、第三方 AI API 或混合方案。
