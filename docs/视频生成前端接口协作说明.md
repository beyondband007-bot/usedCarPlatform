## 1. 本次后端范围

视频生成模块已经形成以下后端链路：

1. 查询数字人。
2. 查询已完成风格提取的参考项。
3. 上传车辆外观图、内饰图和额外参考图。
4. 每个数字人提前上传一段克隆音频，MiniMax 生成并持久化固定 `voice_id`。
5. DeepSeek 根据模板类型、车型或车场信息、参考风格和上传素材生成对应语言的口播草稿。
6. 后端持久化草稿，前端可读取并展示最终提示词。
7. 前端确认后仅提交 `scriptDraftId`，后端用 MiniMax 固定音色生成口播 MP3，再把数字人、车辆图片和口播音频提交给 KIE Seedance 2.0。
8. 前端轮询视频生成任务详情接口，成功后取得视频、封面素材和 MiniMax 口播音频信息。
9. 前端可以查询视频历史、取消运行中任务，以及从终态任务重新生成。

参考视频只用于提前提取风格和场景。运行时不会上传参考视频，用户选择参考项等价于选择对应的 1-2 句预设风格提示词。

前端不需要拼接 KIE Prompt，也不需要直接访问 KIE。

## 2. 固定生成参数

| 参数 | 固定值 |
| --- | --- |
| KIE 模型 | `bytedance/seedance-2` |
| 视频时长 | `15` 秒 |
| 清晰度 | `720p` |
| 画面比例 | `9:16` |
| 口播模型 | MiniMax `speech-2.8-hd` |
| 口播语言 | `zh-CN`、`en`、`yue`，默认 `zh-CN` |
| Seedance 音频 | 1 条 `reference_audio_urls`，`generate_audio=false` |
| 镜头时间轴 | `0-3s`、`3-7s`、`7-12s`、`12-15s` |

前端不要提供其他时长或清晰度选项。

## 3. 鉴权

以下接口均使用现有登录 Token：

```http
Authorization: Bearer <token>
```

后端会重新校验草稿和所有素材均属于当前用户，不能跨用户复用 `scriptDraftId` 或 `assetId`。

## 4. 获取基础选项

### 4.0 获取原型工作流契约

```http
GET /api/v1/modules/video-generation/workflow-contract
```

该接口是前端原型接入的统一入口，返回：

- `templateId`、`digitalHumanId`、`assetId`、`scriptDraftId`、`taskId` 的职责。
- 固定输出：15 秒、720p、9:16。
- 可选口播语言：普通话、英文、粤语。
- 四种模板类型的素材可用状态。
- 完整调用顺序。

当前 `templateId` 与旧链路的 `referenceMaterialId` 使用同一个值。新前端统一提交 `templateId`，旧接口继续兼容 `referenceMaterialId`。

### 4.1 原型模板列表

```http
GET /api/v1/modules/video-generation/templates
GET /api/v1/modules/video-generation/templates?type=single-car
GET /api/v1/modules/video-generation/templates?style=professional
GET /api/v1/modules/video-generation/templates?search=展厅
```

当前已有素材映射：

| 原型模板类型 | 可用数量 | 状态 |
| --- | ---: | --- |
| 单车品介绍 | 3 | 可选择，现有生成链路可用 |
| 促销活动 | 2 | 可选择，专属文案和视频链路可用 |
| 车场介绍 | 1 | 可选择，专属文案和视频链路可用 |

每个模板返回：

### 4.2 动态输入预校验

```http
POST /api/v1/modules/video-generation/templates/{templateId}/validate-inputs
Content-Type: application/json
```

该接口只校验模板字段结构和数量，不代替素材上传时的文件格式、用户归属和 `purpose` 校验。

单车介绍示例：

```json
{
  "brand": "丰田",
  "modelYear": "2025",
  "displacement": "2.0L",
  "salesName": "运动版",
  "series": "凯美瑞",
  "vehicleExteriorAssetIds": ["asset_exterior_01"],
  "vehicleInteriorAssetIds": [],
  "digitalHumanId": "dh-female-01",
  "language": "zh-CN",
  "userReferenceAssetIds": []
}
```

促销活动在单车字段基础上必须增加：

```json
{
  "promotionText": "限时赠送检测服务，到店权益以门店确认结果为准"
}
```

车场介绍不要求车型字段和车辆外观图，改为：

```json
{
  "dealershipName": "安心二手车展厅",
  "dealershipImageAssetIds": ["asset_showroom_01"],
  "digitalHumanId": "dh-female-02",
  "language": "zh-CN",
  "featuredVehicleNames": "家用轿车、城市SUV",
  "userReferenceAssetIds": []
}
```

后端返回 `valid` 和 `issues`。前端可根据模板的 `inputRequirements` 动态渲染素材表单。

原型字段 `nian`、`paiLiang` 在草稿接口中也可直接使用；规范字段分别为 `modelYear`、`displacement`。后端会把品牌、年款、排量、车型和车系自动组合为标准 `vehicleName`。旧调用仍可直接提交完整的 `vehicleName`。

### 4.3 数字人列表

```http
GET /api/v1/modules/video-generation/digital-humans
```

前端只展示 `previewUrl`，提交时使用 `id`。`voiceStatus` 为 `ready` 时才允许提交视频任务。

### 4.4 查询数字人固定音色

```http
GET /api/v1/modules/video-generation/digital-humans/{digitalHumanId}/voice
```

未配置时返回 `status=not_configured`；完成克隆后返回 `status=ready`、`voiceId` 和 `model`。

### 4.5 上传并克隆数字人音色

```http
POST /api/v1/modules/video-generation/digital-humans/{digitalHumanId}/voice-clone
Content-Type: multipart/form-data
```

字段 `file` 支持 `.mp3`、`.m4a`、`.wav`，最大 20 MB。该接口属于数字人准备工作，每个人只需配置一次，不应在每次生成视频时调用。

### 4.6 兼容接口：预设风格列表

```http
GET /api/v1/modules/video-generation/reference-materials
```

前端展示 `title`、`previewUrl` 和 `styleTags`，提交时使用 `id`。后端返回的 `stylePrompt` 固定为 1-2 句话，`generationMode` 为 `preset_prompt_only`。

`previewUrl` 只用于前端帮助用户选择风格，不会作为生成模型输入。视频类型、场景、灯光和镜头节奏由该预设提示词决定。

## 5. 上传车辆素材

```http
POST /api/v1/assets/upload
Content-Type: multipart/form-data
```

字段：

| 字段 | 说明 |
| --- | --- |
| `file` | 图片文件 |
| `purpose` | `car_exterior`、`car_interior` 或 `video_reference_image` |

数量限制：

| 素材 | 原型表单上限 | 兼容旧草稿接口上限 | Seedance 实际选取 |
| --- | ---: | ---: | ---: |
| 外观图 | 5 | 6 | 前 5 张 |
| 内饰图 | 5 | 6 | 前 3 张 |
| 额外参考图 | 4 | 4 | 前 2 张 |
| 车场/展厅图 | 6 | 6 | 前 6 张 |

Seedance 实际接收 1 张数字人身份图、最多 10 张车辆或展厅相关图片和 1 条 MiniMax 口播音频。参考视频不会上传，也不占参考文件数量。


响应关键字段：

```json
{
  "scriptDraftId": "video_script_xxx",
  "templateId": "ref-video-001",
  "status": "ready_for_video_generation",
  "vehicleName": "2018款 捷途 X70 自动悦行版 1.5T",
  "structuredVehicle": {
    "brand": "捷途",
    "modelYear": "2018",
    "displacement": "1.5T",
    "salesName": "自动悦行版",
    "series": "X70"
  },
  "language": "zh-CN",
  "durationSeconds": 15,
  "outputRatio": "9:16",
  "videoResolution": "720p",
  "requiredInputs": {
    "digitalHuman": {},
    "referenceMaterial": {},
    "script": {
      "vehicleProfile": {},
      "scriptText": "口播正文",
      "shotCues": [],
      "generator": "deepseek"
    },
    "uploadedReferences": {}
  },
  "finalVideoPrompt": "最终视频提示词",
  "riskNotes": []
}
```

前端审核页重点展示：

- `requiredInputs.script.scriptText`
- `requiredInputs.script.vehicleProfile`
- `requiredInputs.script.shotCues`
- `finalVideoPrompt`
- `riskNotes`

`generator` 可能为：

| 值 | 含义 |
| --- | --- |
| `deepseek` | 使用 DeepSeek 文案 |
| `deepseek_safety_fallback` | DeepSeek 文案触发安全规则，使用后端安全文案 |
| `local_fallback_after_deepseek_error` | DeepSeek 请求或 JSON 异常，使用后端安全文案 |
| `local_fallback` | 未配置 DeepSeek，使用后端安全文案 |

模板专属规则：

| 模板 | 必须进入文案的内容 | 禁止编造 |
| --- | --- | --- |
| `single-car` | 车型定位、目标用户或使用场景、至少 2 个稳妥卖点 | 价格、里程、事故、具体配置和车况承诺 |
| `promotion` | 单车信息和用户填写的 `promotionText` | 未提供的优惠、金融政策和适用资格 |
| `dealership` | `dealershipName`、真实场地、可选主推车型 | 实时库存、价格、服务承诺和不存在的场地 |

语言映射：

| 前端值 | DeepSeek 文案 | MiniMax `language_boost` |
| --- | --- | --- |
| `zh-CN` | 普通话中文 | `Chinese` |
| `en` | 英文 | `English` |
| `yue` | 粤语 | `Chinese,Yue` |

```http
POST /api/v1/modules/video-generation/tasks
Content-Type: application/json
```

请求：

```json
{
  "scriptDraftId": "video_script_xxx"
}
```

响应示例：

```json
{
  "taskId": "task_xxx",
  "scriptDraftId": "video_script_xxx",
  "templateId": "ref-video-001",
  "templateType": "single-car",
  "language": "zh-CN",
  "moduleCode": "video-generation",
  "status": "queued",
  "progress": 5,
  "kieTaskId": "kie_task_xxx",
  "model": "bytedance/seedance-2",
  "durationSeconds": 15,
  "outputRatio": "9:16",
  "videoResolution": "720p",
  "generateAudio": false,
  "narrationAudio": {
    "provider": "minimax",
    "model": "speech-2.8-hd",
    "voiceId": "ucp_dh_female_01_xxx",
    "durationMs": 13800,
    "speed": 1,
    "url": "http://localhost:3101/results/video-generation/narration-audio/task_xxx.mp3"
  },
  "inputReferenceCount": 11,
  "mediaSummary": {
    "digitalHumanCount": 1,
    "narrationAudioCount": 1,
    "styleVideoCount": 0,
    "stylePromptApplied": true,
    "exteriorImageCount": 5,
    "interiorImageCount": 3,
    "userReferenceImageCount": 0
  },
  "pollingUrl": "/api/v1/modules/video-generation/tasks/task_xxx"
}
```

后端提交给 Seedance 的图片引用顺序：

1. `#image1`：数字人四视图和人物特写身份板。
2. `#image2` 起：用户车辆外观、内饰和额外参考图。

音频引用：

1. `#audio1`：MiniMax 使用所选数字人的固定克隆音色，根据草稿口播正文生成的完整口播。
2. Seedance 关闭自身配音，数字人口型、停顿和语速必须跟随 `#audio1`。
3. 如果首轮口播超过目标时长，后端会根据真实音频时长自动调整语速并重试一次；仍超过 15 秒时任务创建失败，需要缩短文案。

用户选择的参考项通过 `stylePreset` 写入任务请求：

```json
{
  "referenceMaterialId": "ref-video-001",
  "mode": "preset_prompt_only",
  "uploadedToKie": false,
  "prompt": "1-2句预设风格与场景提示词"
}
```

## 9. 任务详情与轮询

```http
GET /api/v1/modules/video-generation/tasks/{taskId}
```

旧通用接口 `GET /api/v1/tasks/{taskId}` 继续兼容，新页面统一使用视频模块接口。

建议每 5 秒轮询一次，直到状态进入终态：

- `success`
- `fail`
- `canceled`

成功响应关键字段：

```json
{
  "taskId": "task_xxx",
  "moduleCode": "video-generation",
  "status": "success",
  "progress": 100,
  "workflowStage": "completed",
  "canCancel": false,
  "scriptDraftId": "video_script_xxx",
  "templateId": "ref-video-001",
  "templateType": "single-car",
  "vehicleName": "2016款 宝马 218i 1.5T",
  "language": "zh-CN",
  "activeModel": "bytedance/seedance-2",
  "resultVideos": [
    {
      "url": "http://localhost:3101/results/video-generation/video-generation_xxx.mp4",
      "sourceUrl": "https://...",
      "localPath": "D:\\usedCarPlatform\\backend\\storage\\results\\video-generation\\video-generation_xxx.mp4",
      "contentType": "video/mp4",
      "size": 1234567
    }
  ]
}
```

为了兼容现有任务结构，视频结果也会同时出现在 `resultImages`。新页面请优先读取 `resultVideos`。

失败时读取：

```json
{
  "error": {
    "code": "KIE_TASK_FAILED",
    "message": "..."
  }
}
```

### 9.1 任务阶段

| `workflowStage` | 含义 |
| --- | --- |
| `preparing_assets` | 后端正在生成 MiniMax 音频并上传素材 |
| `queued` | 已提交 KIE，等待模型处理 |
| `generating` | 视频正在生成 |
| `completed` | 视频生成和本地音频合成完成 |
| `failed` | 任务失败 |
| `canceled` | 用户已取消本地任务 |

非终态建议按响应中的 `pollingRecommendedMs=5000` 轮询。

### 9.2 历史列表

```http
GET /api/v1/modules/video-generation/tasks?page=1&pageSize=20
GET /api/v1/modules/video-generation/tasks?status=success&page=1&pageSize=20
```

列表项包含：

- `taskId`
- `title`
- `vehicleName`
- `templateId`
- `scriptDraftId`
- `status`
- `workflowStage`
- `progress`
- `thumbnail`
- `downloadUrl`
- `resultVideos`
- `error`

### 9.3 取消任务

```http
POST /api/v1/modules/video-generation/tasks/{taskId}/cancel
```

只有 `waiting`、`queued`、`generating` 可以取消。取消后：

- 本地任务立即进入 `canceled`。
- 后端停止轮询，不接受供应商晚到结果覆盖该状态。
- 当前 KIE 接口没有远程撤销能力，已经提交给供应商的任务可能继续运行。
- 重复取消终态任务返回 `409`。

### 9.4 重新生成

```http
POST /api/v1/modules/video-generation/tasks/{taskId}/regenerate
```

只允许对 `success`、`fail`、`canceled` 任务重新生成。后端复用原 `scriptDraftId`，重新生成 MiniMax 音频并创建新的 KIE 任务，响应包含：

```json
{
  "taskId": "task_new",
  "regeneratedFromTaskId": "task_old"
}
```

## 10. 前端状态建议

| 后端状态 | 前端显示 |
| --- | --- |
| `waiting` | 正在准备素材 |
| `queued` | 已进入生成队列 |
| `generating` | 正在生成视频 |
| `success` | 生成完成，可预览和下载 |
| `fail` | 生成失败，展示 `error.message` |
| `canceled` | 任务已取消 |

提交任务后禁用重复提交按钮，避免同一个草稿被误点生成多次。

## 11. 常见错误

| HTTP/错误 | 处理方式 |
| --- | --- |
| `400 scriptDraftId is required` | 检查是否已生成草稿 |
| `404 video script draft not found` | 草稿不存在或不属于当前用户 |
| `404 asset not found` | 素材被删除或属于其他用户 |
| `503 no available kie api key` | 提示稍后重试 |
| `VIDEO_GENERATION_CREATE_FAILED` | 展示后端错误信息，允许重新提交 |
| `KIE_TASK_TIMEOUT` | 任务超过后端 20 分钟截止时间 |
| `409 task is already in a terminal status` | 不要重复取消终态任务 |
| `409 only a completed, failed, or canceled video task can be regenerated` | 等待当前任务进入终态后再重新生成 |
